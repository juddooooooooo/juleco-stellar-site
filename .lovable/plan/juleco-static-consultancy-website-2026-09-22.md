# Juleco static consultancy website

## Scope
- Replace the starter screen with a polished, fully static one-page Juleco website at `/`.
- Add shared responsive navigation and footer, plus complete `/privacy` and `/terms` pages.
- Use only the supplied company details and copy; do not add forms, tracking, stock imagery, or invented claims.

## Design
- Establish the supplied forest green, warm off-white, brass, and near-black palette as reusable site tokens.
- Load Manrope and Inter through the document head.
- Use generous whitespace, restrained geometric details, subtle card lift, smooth anchor scrolling, and a compact mobile menu.
- Build the About artwork from inline geometric SVG/CSS and use Lucide icons for interface and service symbols.

## Implementation
- Create small shared site header, footer, and legal-page layout components.
- Build all six home sections with working anchor and email links.
- Add route-specific titles, descriptions, social metadata, and self-referencing canonical links.
- Create and wire a lightweight `J` favicon and configure static prerendering for all three pages.

## Validation
- Confirm the preview builds without errors.
- Check desktop and mobile layouts, navigation, menu behavior, and key links in the running site.
